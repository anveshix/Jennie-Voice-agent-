.env se kaise alag hai?

API Room — yahan save ki hui key storage/settings.json me jaati hai (git-ignored, chmod 600) aur turant lag jaati hai, restart ki zarurat nahi.

.env — traditional tareeqa, server start hote hi padha jaata hai. Dono me se jo API Room me saved hai wahi pehle chalta hai.

What leaves this browser: your message text and the recent turns of this chat go to the configured AI provider. Jenni’s server does not store chat history.

What stays local: drafts, tasks, notes and the PIN. They are not attached to a request automatically.

Not connected: Google Drive, email and any remote sending. Saving a reply creates a local draft only. The PIN is convenience, not account security.

Send & save elsewhere

Teen alag-alag options — jo zaroorat ho wahi on karo. Baaki band rehne do.

Checking…
1 Telegram Sabse aasan — koi OAuth nahi, koi verification nahi not connected
  1. Telegram me @BotFather kholo → /newbot → naam do.
  2. Token copy karo (123456789:ABC…).
  3. Apne naye bot ko koi bhi message bhejo — "hi" kaafi hai.
  4. Yahan token paste karo → Find my chat → chat chuno → Save.

Bot sirf aapke chat me message bhej sakta hai. Token server par rehta hai (storage/connections.json, mode 600) — browser me kabhi wapas nahi aata.

2 Google Drive — browser mode Sirf client ID · drive.file · no verification off
  1. Google Cloud → naya project → Google Drive API enable karo.
  2. OAuth consent screen → External → apna email test user me daalo.
  3. Credentials → OAuth client ID → Web application.
  4. Authorized JavaScript origin: http://localhost:3000
  5. Client ID copy karke niche paste karo.

App sirf wahi files dekh sakta hai jo woh khud banaye. Poora Drive search nahi hota — uske liye Google ki verification chahiye. Phone se chalane ke liye HTTPS tunnel zaroori hai.

3 Google Drive — server mode Background sync · refresh token · HTTPS chahiye off
  1. Option 2 wala client ID + client secret bhi copy karo.
  2. Redirect URI register karo, jaise https://your-tunnel.example/oauth2callback.
  3. Niche woh redirect URI daal ke Show Google link dabao.
  4. Link kholo → allow karo → browser ka URL copy karo (usme ?code= hoga).
  5. Woh code yahan paste karke Finish connection dabao.

Is link ko kholo: Google authorization

Server mode = browser band hone ke baad bhi upload chal sakta hai. Iska matlab Google ka refresh token disk par rehta hai — bilkul API key jaisa treat karo.
