1. AI provider

2. Phone par install kaise karein

  1. Android Chrome: upar right ⋮ menu → Add to Home screen → Install.
  2. iPhone Safari: Share button → Add to Home Screen.
  3. Home screen par Jenni icon aa jayega — browser jaisa hi khulega, address bar ke bina.

3. Security — ye zaroor padho

  • Key is phone ki browser storage me rehti hai. Phone kho gaya to key bhi ja sakti hai — provider ke dashboard se key revoke kar dena.
  • Provider ke dashboard me spend limit lagao. Free tier wale provider (Groq, Gemini) se shuru karna sabse safe hai.
  • Yeh app aapke phone se seedha provider ko request bhejti hai. Beech me koi Jenni server nahi hai.
  • Public/shared phone par key save na karein.

4. Voice

Mic dabane par browser ka apna speech-to-text chalta hai (Chrome/Android par best). Agar aapka provider transcription model deta hai to recording provider ke paas jaati hai; warna browser speech hi use hota hai.

Drafts + settings ka JSON. Key export me nahi jaati.
