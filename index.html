Checking setup…
  1. Copy .env.example to .env in the project folder.
  2. Set AI_API_KEY and AI_MODEL for your OpenAI-compatible provider.
  3. Run npm start and open http://localhost:3000.
Do not expose this server publicly without authentication and HTTPS. A billable API key on an open server can be misused.

What leaves this browser: your message text and the recent turns of this chat go to the configured AI provider. Jenni’s server does not store chat history.

What stays local: drafts, tasks, notes and the PIN. They are not attached to a request automatically.

Voice: browser speech recognition may use your browser’s speech service. If a recording fallback is used, its audio goes to the configured transcription provider.

Not connected: Google Drive, email and any remote sending. Saving a reply creates a local draft only. The PIN is convenience, not account security.
